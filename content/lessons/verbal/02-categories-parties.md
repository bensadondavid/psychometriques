# Catégorie ou partie : classer sans confondre

**Une rose est une fleur. Un pétale est une partie d'une fleur.** Les deux phrases contiennent « fleur », mais elles décrivent deux structures différentes. Cette distinction permet d'éliminer des réponses qui paraissent pourtant très proches.

**Votre mission :** reconnaître si le premier mot désigne un type du second, une composante du second, un membre d'un groupe ou simplement quelque chose qui se trouve dans le second.

## Avant de commencer — Deux liens à séparer

A. corde : violon  
B. marteau : outil  
C. instrument : orchestre  
D. musicien : violon

<details><summary>Correction</summary>

**B.** Un violon est un instrument ; un marteau est un outil. Une corde est une partie d'un violon, pas une sorte de violon. C désigne un élément d'un ensemble musical ; D une personne et son instrument.

</details>

<!-- interaction L02-D2 | QCM unique | competence: partie-ensemble -->
**D2. couplet : chanson —**

A. chanson : œuvre  
B. chanteur : chanson  
C. chapitre : roman  
D. chanson : couplet

<details><summary>Correction</summary>

**C.** Un couplet est une subdivision d'une chanson ; un chapitre est une subdivision d'un roman. A classe la chanson dans une catégorie ; D inverse la direction ; B donne un interprète et une œuvre.

</details>

Indiquez votre confiance. Une bonne réponse trouvée grâce au thème doit être justifiée par une phrase avant de compter comme acquise.

## Séquence 1 — La catégorie répond à « quelle sorte de chose ? »

Dans **saumon : poisson**, le premier mot appartient à la catégorie nommée par le second. La phrase test est : **« Un X est un Y »**, au sens de type ou d'exemple.

Exemples : un chêne est un arbre ; un sonnet est un poème ; un triangle est un polygone. Le premier terme peut désigner un type précis, pas nécessairement un individu unique.

L'inverse ne se déduit pas : tout saumon est un poisson, mais tout poisson n'est pas un saumon. Cette asymétrie donne le sens de la relation.

### Le niveau de précision

« Chêne : arbre » et « chêne : végétal » sont deux relations de catégorie vraies. Si elles figurent dans des réponses concurrentes, il faut examiner le modèle : catégorie immédiate ou catégorie plus large ? Une question bien construite doit fournir assez d'éléments pour distinguer une meilleure réponse.

N'ajoutez pas une hiérarchie arbitraire pour forcer un choix. « Type précis vers catégorie générale » reste parfois le seul niveau justifié.

## Séquence 2 — La partie répond à « de quoi est-ce composé ? »

Dans **roue : voiture**, le premier terme constitue une composante du second. La phrase test est : **« X est une partie de Y. »**

Le test de catégorie échoue : une roue n'est pas une voiture. Inversement, un saumon n'est pas une portion du corps d'un poisson ; c'est un poisson entier.

| Paire | Test « est un » | Test « fait partie de » | Relation retenue |
|---|---|---|---|
| rose : fleur | Oui | Pas au sens de composante | Type → catégorie |
| pétale : fleur | Non | Oui | Partie → ensemble |
| chapitre : livre | Non | Oui | Subdivision → œuvre |
| tiroir : commode | Non | Oui | Composante → objet |

Les parties peuvent être matérielles, comme un tiroir, ou organisationnelles, comme le chapitre d'un ouvrage.

### Atelier — Deux colonnes, deux tests

Classez : **carré : rectangle ; touche : clavier ; cuivre : métal ; strophe : poème ; moineau : oiseau ; branche : arbre**.

Pour chaque paire, complétez une seule phrase : « X est un Y » ou « X est une partie de Y ».

<details><summary>Correction</summary>

**Catégorie :** carré : rectangle ; cuivre : métal ; moineau : oiseau. Un carré est un rectangle particulier, dont les quatre côtés ont la même longueur.

**Partie :** touche : clavier ; strophe : poème ; branche : arbre. Une touche n'est pas une sorte de clavier ; une strophe n'est pas, par définition, un poème entier.

</details>

## Séquence 3 — Membre d'un groupe et contenu d'un lieu

Toutes les relations « dans » ne sont pas des relations partie–tout de même nature.

| Paire | Phrase précise |
|---|---|
| musicien : orchestre | Le premier est un membre du groupe nommé par le second. |
| abeille : essaim | Le premier est un individu d'un groupe du second type. |
| moteur : voiture | Le premier est un composant du second. |
| livre : bibliothèque | Le premier est un objet conservé ou proposé dans le lieu nommé par le second. |

Un musicien peut être membre d'un orchestre sans être une pièce matérielle. Un livre reste un livre lorsqu'on le sort de la bibliothèque : sa présence dans un lieu ne le transforme pas automatiquement en composant de ce lieu.

Dans certaines analogies, « membre → ensemble » constitue une famille assez large pour rapprocher des cas. Si plusieurs réponses utilisent cette famille, affinez : groupe d'individus, structure matérielle, collection ou lieu de conservation.

## Séquence 4 — Conserver la direction et la distance

Pour **livre : chapitre**, la phrase est « le premier est subdivisé en éléments du second type ». Une réponse **chanson : couplet** conserve l'ordre ; **pétale : fleur** le retourne.

La relation doit aussi rester à une distance comparable. « Lettre : mot » désigne un élément d'écriture et l'unité qu'il compose ; « lettre : bibliothèque » ajoute des étapes et un lieu. Le simple fait qu'on puisse raconter une chaîne ne suffit pas.

<!-- interaction L02-I2 | reconstruction | competence: orientation -->
### Atelier — Réparez le raisonnement

Un élève écrit : « Le modèle est **voiture : moteur**. Je choisis **aile : avion**, car un moteur et une aile sont des parties de véhicules. »

Quelle correction lui apporter ? Proposez une paire qui conserve la relation du modèle.

<details><summary>Correction</summary>

L'élève a identifié la bonne famille mais inversé l'ordre. Il faut **avion : aile** : le premier est l'ensemble et le second une composante. Reconnaître la famille ne dispense pas de vérifier la direction.

</details>

## Séquence 5 — Ce qu'il ne faut pas transformer en règle

- Une chose petite n'est pas nécessairement une partie : un petit chien est un chien entier.
- Une chose contenue n'est pas nécessairement une composante : une pomme dans un sac n'est pas une pièce du sac.
- Deux objets qui se ressemblent ne sont pas forcément dans une relation de catégorie : une baleine ressemble extérieurement à un poisson, mais c'est un mammifère.
- « Fait de » renvoie souvent à la matière : « vitre : verre » diffère de « fenêtre : vitre ».
- Les relations doivent reposer sur un sens courant et stable, pas sur un cas exceptionnel inventé.

### Atelier — La même idée au bon niveau

**violoniste : quatuor —**

A. corde : violon  
B. choriste : chœur  
C. violon : instrument  
D. scène : concert

<details><summary>Correction</summary>

**B.** Dans ce contexte, le violoniste est un membre d'un ensemble musical ; le choriste est un membre d'un autre ensemble musical. A est une composante matérielle d'un instrument ; C une catégorie ; D un lieu et un événement. B conserve plus précisément la nature du lien que A.

</details>

**F6. acte : pièce de théâtre —** A. strophe : poème ; B. acteur : pièce de théâtre ; C. théâtre : pièce ; D. comédie : pièce de théâtre.

<details><summary>Corrigé détaillé</summary>

**F1 : D.** Type vers catégorie. A est une partie ; B un créateur ; C va de l'œuvre à une subdivision.

**F2 : A.** Partie matérielle vers objet. B donne une matière en ordre inversé par rapport à objet–matière ; C un type ; D une destination corporelle.

**F3 : C.** Ensemble vers partie. A inverse cette direction ; B classe ; D renvoie à la matière.

**F4 : B.** Membre vers groupe organisé. A désigne un objet et un support ; C une composante anatomique ; D une fonction.

**F5 : D.** Le cuivre est un métal, comme un triangle est un polygone. A porte sur la matière d'un objet ; B sur l'outil et son objet d'action ; C inverse la relation.

**F6 : A.** Subdivision d'une œuvre vers œuvre. D est attirante, mais une comédie est une sorte de pièce, pas une partie de pièce. B et C indiquent un participant et un lieu.

</details>

## Votre fiche de révision

**Catégorie : « X est un Y. » Partie : « X est une composante de Y. » Groupe : « X est membre de Y. » Lieu : « X se trouve ou est conservé dans Y. »**

Identifiez la famille, gardez l'ordre et choisissez la formulation qui distingue réellement les candidats.
